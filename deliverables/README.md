# Deliverables

The three things submitted for this course project.

| Deliverable | Where | What it is |
|-------------|-------|------------|
| Report | [report/](report/) | Research-style report (`.docx`, plus `.pdf` if you want one) |
| Presentation | [presentation/](presentation/) | The slide deck used in the presentation and demo (`.pptx`, plus `.pdf` if you want one) |
| Working model | [../src/](../src/), [../README.md](../README.md) | The Java program, tests and scripts; run it with `run.sh` or `run.bat` |

Every number in the report and the slides traces to a file in [../results/](../results/), produced by a script in [../scripts/](../scripts/).
